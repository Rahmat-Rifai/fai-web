# Portfolio Web

Personal portfolio site built with React, TypeScript, Vite, and Tailwind CSS.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

1. Masuk ke direktori app:
   ```bash
   cd app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Jalankan development server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```

Hasil build tersimpan di folder `app/dist`.
